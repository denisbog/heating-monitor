Chart admin

Choose how many charts the dashboard shows and what each one plots. A chart reads either the cloud readings (heat pump and thermostats) or the ingest sensors (devices that push to /v1/samples); ingest charts also choose their timeline — upload time (server clock) or device time (the clock the firmware reported). Changes are stored server-side and apply to every client. An admin token (API_TOKEN) is required to save.

Device ingest

Devices that push samples to /v1/samples. A device key is shown once — when it is created or rotated — and cannot be read back afterwards.

Register a device

The id is the device's BLE address without separators. Registering an existing id replaces its key and re-enables it.

Recent samples

The last stored samples, newest first (server time). The device time is what the firmware reported when it queued the sample — — means the device had no clock yet.
